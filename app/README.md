# 마실 — 웹앱 (프로토타입)

간단한 모바일·데스크톱 대응 HTML 프로토타입입니다.

사용 방법

1. 파일을 로컬에서 열려면 `마실/app/index.html`을 브라우저에서 엽니다.
2. 이 프로토타입에는 다음 모듈이 포함되어 있습니다:
	- 모의 `PASS` 인증 UI (백엔드 연동 전 테스트용)
	- 검색 가능한 스킬 셀렉터(칩 형태)
	- 3단계 카테고리 선택(대분류/중분류/소분류) 및 예제 항목
	- 추천 연결 미리보기 페이지: `recommendations.html` (샘플 이미지 포함)
3. 실제 공공데이터 연동, 인증, 백엔드는 포함되어 있지 않습니다. 이 프론트엔드는 프로토타입 UI입니다.

배포 (GitHub Pages)

1. 이 폴더를 새로운 GitHub 리포지토리에 푸시합니다 (원격 이름 예: `origin`, 기본 브랜치 `main`).
2. 위에 포함된 GitHub Actions 워크플로우(`.github/workflows/gh-pages.yml`)는 `main` 브랜치에 푸시될 때 `app/` 폴더를 GitHub Pages로 자동 배포합니다.
3. 배포 후 URL은 `https://<your-github-username>.github.io/<repo>/` 형태가 됩니다.

간단 수동 배포 방법(대체):

1. GitHub 저장소 생성 → 로컬에서 연결 → push
2. 리포지토리 Settings → Pages → Source에서 `gh-pages` 브랜치 또는 `main` 브랜치의 `/app` 폴더를 선택하여 배포할 수 있습니다.
